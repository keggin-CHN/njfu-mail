# 04. 附件与正文内嵌图片下载接口 (Attachments & Inline Images)

本模块解决收作业场景中最关键的痛点：**学生既可能上传标准附件（图片/PDF），也可能直接在手机端把作业照片贴在邮件正文中**。本接口文档详细说明这两类资源的下载与处理规范。

---

## 接口一：标准附件下载 (Regular Attachments)

- **请求方式**：`GET`
- **请求 URL**：`https://mail.njfu.edu.cn/cgi-bin/download`
- **Query 参数表**：

| 参数名 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| `sid` | string | 会话令牌 | `Trx-hF5nyf8TnRx2,7` |
| `mailid` | string | 邮件 ID | `ZL0005-7hwXkEp9yP4S1lc9SRLjX0n` |
| `id` / `fileid` | string | 附件的唯一标识号 | 例如 `1` 或 `0` |
| `filename` | string | 原始文件名（用于 Content-Disposition 校验） | `IMG_20261105_155514.jpg` |

### 1. 详情页中的附件链接识别
从详情页 HTML 中提取附件链接：
```python
# 1. 静态 <a> 标签形式
re.findall(r'<a[^>]+href="([^"]*?/cgi-bin/download[^"#]*)"[^>]*>(.*?)</a>', detail_html)

# 2. JS downloadAttach 函数调用形式
re.findall(r"downloadAttach\((.*?)\)", detail_html)
```

### 2. 文件名解码与防乱码处理
下载响应中通常包含 `Content-Disposition` 响应头：
```http
Content-Disposition: attachment; filename="2410403104%E9%83%AD%E4%BD%B3%E8%89%BA.jpg"; filename*=UTF-8''2410403104%E9%83%AD%E4%BD%B3%E8%89%BA.jpg
```
解码逻辑需覆盖：
- RFC 2047 MIME 编码 (`=?utf-8?B?...?=`)
- URL 编码 (`%E9%83%AD...`)
- Latin1 到 UTF-8 / GB18030 的双重乱码修复 (Mojibake repair)

## 接口二：正文内嵌贴图抓取 (Inline Images)

> [!CAUTION]
> 很多同学使用手机 QQ 邮箱或微信写邮件时，直接点击“添加图片”插入在正文中，此时系统不会生成标准附件，邮件详情中的附件数显示为 0！如果仅抓取附件，会导致作业严重漏收！

- **请求方式**：`GET`
- **请求 URL**：`https://mail.njfu.edu.cn/cgi-bin/viewfile`
- **Query 参数表**：

| 参数名 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| `f` | string | 文件的专属临时 Hash 凭证 | `526AC86DCD621691614560...` |
| `usewmcache` | string | 水印缓存控制 | `1` |
| `sid` | string | 会话令牌 | `Trx-hF5nyf8TnRx2,7` |

### 提取与下载逻辑：
```python
# 1. 从正文容器 mailContentContainer 中提取 viewfile 图片链接
img_matches = re.findall(r'<img[^>]+src=["\']([^"\']+)["\']', content_html)
for src in img_matches:
    if "viewfile" in src or "readmail" in src:
        # 补全协议和域名
        full_url = "https://mail.njfu.edu.cn" + src if not src.startswith("http") else src
        
        # 确保附带当前会话的 sid
        if "sid=" not in full_url:
            full_url += f"&sid={sid}"
            
        resp = session.get(full_url)
        # 直接写入二进制文件
        with open("学号姓名.jpg", "wb") as f:
            f.write(resp.content)
```

## 接口三：PDF 格式作业自动栅格化为高清图片

针对提交 PDF 格式作业的同学，利用 `pymupdf` 将 PDF 页面无损渲染为 200 DPI 的 JPG 图片，方便老师/助教统一用相册或图库批阅：

```python
import os
import pymupdf

def render_pdf_to_jpg(pdf_bytes, output_jpg_path, dpi=200):
    doc = pymupdf.open(stream=pdf_bytes, filetype="pdf")
    for page_idx in range(len(doc)):
        page = doc[page_idx]
        pix = page.get_pixmap(dpi=dpi)
        if len(doc) == 1:
            save_path = output_jpg_path
        else:
            base, ext = os.path.splitext(output_jpg_path)
            save_path = f"{base}_{page_idx + 1}{ext}"
        pix.save(save_path)
```
