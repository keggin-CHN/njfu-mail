# 南京林业大学邮箱 (mail.njfu.edu.cn) 接口协议与复用指南

本项目针对南京林业大学校园邮箱系统（基于腾讯企业邮箱 Tencent Exmail 深度定制）的 Web 端协议进行了完整逆向与接口分析，用于自动化邮件抓取、作业批量收集、附件与正文图片自动提取。

## 核心基础信息

- **网页端首页**：`https://mail.njfu.edu.cn/`
- **底层架构**：腾讯企业邮箱 (Tencent Exmail)
- **会话鉴权方式**：URL Query / Cookie 中的 `sid`（Session ID）
- **加密体系**：RSA-1024 + PKCS#1 v1.5 + Base64
- **推荐运行环境**：
  - Python 3.9+
  - `curl_cffi`（关键：模拟 Chrome TLS ClientHello 指纹）
  - `pycryptodome`（用于 RSA 密码加密）
  - `pymupdf`（用于学生提交的 PDF 自动栅格化为高清图片）
