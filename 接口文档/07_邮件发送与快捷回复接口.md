# 07. 邮件发送与快捷回复接口 (Send & Reply Mail API)

南京林业大学邮箱（基于腾讯企业邮箱 Tencent Exmail）提供了 Web 端写信与快捷回复能力。由于系统启用了动态 CSRF Token 防护，发信必须遵循**“加载写信模板 -> 提取动态 Token -> 组装参数 POST 发送”**的两阶段流程。

---

## 接口调用流程图

```
客户端 -> GET /cgi-bin/readtemplate?action=reply (或 compose_new) -> 获取隐藏 Token 及表单模板
客户端 -> POST /cgi-bin/compose_send (携带动态 Token + 正文 + 收件人) -> 发送成功，存入已发送箱
```

---

## 阶段一：获取写信/回复模板与 CSRF Token

- **请求方式**：`GET`
- **请求 URL**：`https://mail.njfu.edu.cn/cgi-bin/readtemplate`
- **Query 参数表**：

| 参数名 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| `action` | string | 动作类型 | `reply`（回复邮件）或 `compose_new`（新写信） |
| `t` | string | 页面模板名 | 固定为 `compose` |
| `sid` | string | 当前会话令牌 | `Trx-hF5nyf8TnRx2,7` |
| `mailid` | string | 目标邮件 ID（**仅回复时需要**） | `ZL0005-c4Hslkx6IhT4kxJ4TvY9Z0n` |

### 响应解析要点
在返回的 HTML 中，表单 `<form name="frm" action="/cgi-bin/compose_send">` 包含了数十个预置参数及一个由系统动态生成的 32 位 MD5 随机防伪字段（CSRF Token）：
```html
<input type="hidden" name="91451bdb3bfc8a4d2301d194469e24e8" value="ff7b847a92a84265a5d490242842b2d8" />
```
> [!IMPORTANT]
> 必须完整保留该表单内的所有 `<input type="hidden">` 参数并随同发信请求一并提交，否则服务器会返回安全验证错误或拒绝发送。

---

## 阶段二：提交发送邮件 (`compose_send`)

- **请求方式**：`POST`
- **请求 URL**：`https://mail.njfu.edu.cn/cgi-bin/compose_send?sid={sid}`
- **Content-Type**：`application/x-www-form-urlencoded`
- **关键 Body 参数表**：

| 参数名 | 类型 | 必填 | 说明与示例 |
| :--- | :--- | :---: | :--- |
| `to` | string | 是 | 收件人地址，例如 `2813264791@qq.com` |
| `cc` | string | 否 | 抄送人列表 |
| `bcc` | string | 否 | 密送人列表 |
| `subject` | string | 是 | 邮件主题，例如 `回复：2410610311皮弘誉 2410610528周潘垚` |
| `content__html`| string | 是 | HTML 格式正文内容，例如 `<div>同学你好：...</div>` |
| `actiontype` | string | 是 | 固定值：`send` |
| `savesendbox`| string | 是 | 是否保存到“已发送”：`1` 为保存，`0` 为不保存 |
| `sid` | string | 是 | 会话令牌 |
| `sendname` | string | 是 | 固定值：`alias` |
| `acctid` | string | 是 | 账户编号，默认 `0` |
| `s` | string | 是 | 操作标识，默认 `comm` |
| *(动态 Token)*| string | 是 | 第一阶段从模板解析出的 32 位 MD5 键值对 |

---

## 阶段三：发送结果判定

提交后服务器返回 HTTP 200，并在响应页面包含发送结果状态：
- 成功标识：页面包含 `mail_sent`、`发送成功` 或带有成功提示的 JS 跳转代码。
- 失败排查：若返回包含 `verifycode` 则说明触发了人机验证码；若提示 `system error` 说明 CSRF Token 缺失或已过期。

---

## Python 实战代码封装

```python
import re

def send_reply(session, sid, mailid, to_addr, subject, html_body):
    """回复指定邮件"""
    # 1. 获取回复模板表单
    template_url = f"https://mail.njfu.edu.cn/cgi-bin/readtemplate?action=reply&mailid={mailid}&t=compose&sid={sid}"
    resp = session.get(template_url)
    resp.raise_for_status()

    # 2. 提取 form[name="frm"] 的全部 hidden 字段
    form_m = re.search(r'<form[^>]+name="frm"[^>]*>(.*?)</form>', resp.text, re.S)
    if not form_m:
        raise RuntimeError("未在模板页面中解析到 frm 表单")
    
    payload = {}
    for inp in re.finditer(r'<input[^>]+>', form_m.group(1)):
        name_m = re.search(r'name=["\']([^"\']+)["\']', inp.group(0))
        val_m = re.search(r'value=["\']([^"\']*)["\']', inp.group(0))
        type_m = re.search(r'type=["\']([^"\']+)["\']', inp.group(0))
        if not name_m:
            continue
        t = type_m.group(1).lower() if type_m else "text"
        if t in ("button", "submit", "reset"):
            continue
        payload[name_m.group(1)] = val_m.group(1) if val_m else ""

    # 3. 填充发送目标与正文
    payload["to"] = to_addr
    payload["subject"] = subject
    payload["content__html"] = html_body
    payload["actiontype"] = "send"
    payload["savesendbox"] = "1"
    payload["sid"] = sid

    # 4. 提交发信
    send_url = f"https://mail.njfu.edu.cn/cgi-bin/compose_send?sid={sid}"
    send_resp = session.post(send_url, data=payload)
    send_resp.raise_for_status()

    if "成功" in send_resp.text or "mail_sent" in send_resp.text:
        return True, "发送成功"
    return False, send_resp.text[:300]
```
