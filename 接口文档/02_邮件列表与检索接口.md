# 02. 邮件列表与检索接口 (Mail List API)

本接口用于分页检索邮箱各个文件夹（收件箱、草稿箱、已发送、垃圾箱）中的邮件概览列表，获取每封邮件的 `mailid` 及接收时间戳。

---

## 接口说明

- **请求方式**：`GET`
- **请求 URL**：`https://mail.njfu.edu.cn/cgi-bin/mail_list`
- **Query 参数表**：

| 参数名 | 类型 | 说明 | 推荐取值 |
| :--- | :--- | :--- | :--- |
| `sid` | string | 登录获取的会话令牌 | 例如 `Trx-hF5nyf8TnRx2,7` |
| `folderid` | string | 邮箱文件夹 ID | `1`（收件箱）<br>`6`（垃圾箱/垃圾邮件，**必检避坑**）<br>`3`（已发送）<br>`5`（已删除/废件箱）<br>`4`（草稿箱） |
| `page` | int / string | 页码（**从 0 开始计数**） | `0` 为第 1 页，`1` 为第 2 页 |
| `s` | string | 操作行为 | `getmail` |
| `today_tips` | string | 提醒参数 | `400` |
| `loc` | string | 来源视图框架 | `frame_html,,,22` |

---

## 响应解析规范

### 1. 解析分页总数
在返回的 HTML 中，分页控制栏包含当前页和总页数：
```html
<span class="page">1 / 19 页</span>
```
- **正则匹配**：
  ```python
  total_pages = int(re.search(r'(\d+)\s*/\s*(\d+)\s*页', html_text).group(2))
  ```

### 2. 解析每页的邮件条目
每一封邮件在列表表格的复选框或行属性中，都有 `totime`（UTC 毫秒时间戳）和 `mailid`（唯一邮件标识符）：
```html
<input type="checkbox" totime="1793865950000" name="mailid" value="ZL0005-QbNt2gA4WG6CrSxGD5vmK0n" ... />
```
- **正则匹配**：
  ```python
  pattern = re.compile(r'totime="(\d+)"[^>]*name="mailid"\s+value="([^"]+)"', re.S)
  entries = [(mailid, int(totime)) for totime, mailid in pattern.findall(html_text)]
  ```

## 日期区间过滤策略

由于列表是按时间倒序排列的（最新邮件在前），在按时间筛选作业时可采取**早停优化（Early-stopping）**：

```python
from datetime import datetime

start_dt = datetime.strptime("2026-10-30", "%Y-%m-%d")
start_ms = int(start_dt.timestamp() * 1000)

matched_entries = []
stop_search = False

for page in range(total_pages):
    html = fetch_inbox_page(session, sid, page)
    entries = parse_mail_entries(html)
    
    for mailid, totime in entries:
        if totime < start_ms:
            # 已经早于目标起始时间，无需继续向下翻页
            stop_search = True
            break
        matched_entries.append((mailid, totime))
        
    if stop_search:
        break
```

## 重要机制：垃圾箱（Spam / Junk）检索策略

高校邮件系统具备反垃圾邮件拦截过滤机制。在作业收集中，常有同学因为**邮件无正文、标题过短、附件为生僻实拍图**或者**使用第三方邮箱转发**而被学校反垃圾引擎错误归类到“垃圾箱”中（如部分同学的实拍图作业）。

若只扫描收件箱（`folderid=1`），会导致严重漏件。因此完整的作业收集流水线**必须连带扫描垃圾箱（`folderid=6`）**：

```python
# 推荐的标准收件扫描策略：遍历收件箱与垃圾箱
TARGET_FOLDERS = [
    (1, "收件箱"),
    (6, "垃圾箱"),
]

all_entries = []
for fid, f_name in TARGET_FOLDERS:
    folder_entries = client.get_mail_entries(folder_id=fid, max_pages=3)
    all_entries.extend(folder_entries)
```
