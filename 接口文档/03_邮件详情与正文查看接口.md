# 03. 邮件详情与正文查看接口 (Read Mail API)

本接口用于获取指定邮件的完整元数据（发件人、主题、时间）及正文 HTML，并提供清洗与文本提取方案。

---

## 接口说明

- **请求方式**：`GET`
- **请求 URL**：`https://mail.njfu.edu.cn/cgi-bin/readmail`
- **Query 参数表**：

| 参数名 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| `sid` | string | 会话令牌 | `Trx-hF5nyf8TnRx2,7` |
| `mailid` | string | 邮件唯一标识符 | `ZL0005-QbNt2gA4WG6CrSxGD5vmK0n` |

---

## 字段提取规范

### 1. 邮件主题 (Subject)
主题位于 `<span id="subject">` 中：
```html
<span id="subject">2410403104郭佳艺</span>
```
- **正则**：
  ```python
  subject = re.search(r'<span id="subject"[^>]*>(.*?)</span>', detail_html, re.S).group(1)
  ```

### 2. 发件人姓名与邮箱地址 (Sender)
页面内通常有 JSON 对象片段或属性标注：
```html
from: { name: "郭佳艺", addr: "gjy1141627028@outlook.com" }
```
- **备选降级规则**（应对 QQ 邮箱/网易邮箱转发）：
  1. `from:\s*\{\s*name\s*:\s*"([^"]*)"` 与 `from:\s*\{.*?addr\s*:\s*"([^"]*)"`
  2. `mailnick="([^"]*)"`
  3. `fromaddr="([^"]+@[^"]+)"`

### 3. 发信时间 (Date)
```html
date: "2026年11月5日(星期四) 下午3:58"
```
- **正则**：
  ```python
  date_str = re.search(r'date:\s*"([^"]*)"', detail_html).group(1)
  ```

### 4. 正文容器提取 (Mail Body Container)
正文被包裹在独立的容器中：
```html
<div id="mailContentContainer" class="qmbox" ...>
  <!-- 正文 HTML、内联贴图或文本 -->
</div>
```
- **提取正则**：
  ```python
  content_html = re.search(r'<div id="mailContentContainer"[^>]*>(.*?)</div></div></div>', detail_html, re.S)
  if not content_html:
      content_html = re.search(r'<div id="mailContentContainer"[^>]*>(.*?)</div>', detail_html, re.S)
  ```

## 正文文本清洗方案

使用轻量级的 `HTMLParser` 去除标签，保留换行，并去除多余空白字符：

```python
import html
import re
from html.parser import HTMLParser

class SimpleHTMLTextExtractor(HTMLParser):
    BLOCK_TAGS = {"p", "div", "br", "tr", "table", "li", "ul", "ol", "h1", "h2", "h3", "h4", "h5", "h6"}

    def __init__(self):
        super().__init__()
        self.parts = []

    def handle_starttag(self, tag, attrs):
        if tag == "br":
            self.parts.append("\n")

    def handle_endtag(self, tag):
        if tag in self.BLOCK_TAGS:
            self.parts.append("\n")

    def handle_data(self, data):
        if data:
            self.parts.append(data)

    def get_text(self):
        text = "".join(self.parts)
        text = html.unescape(text)
        text = text.replace("\xa0", " ").replace("\r\n", "\n").replace("\r", "\n")
        text = re.sub(r"\n{3,}", "\n\n", text)
        return text.strip()
```
