# 01. 认证与登录接口 (Authentication & Login)

南京林业大学邮箱采用 RSA 非对称加密传输用户凭据，整个登录流程分为两阶段：获取时间戳与密钥 -> 密文 POST 登录获取会话令牌 `sid`。

---

## 阶段一：获取登录页与时间戳

- **请求方式**：`GET`
- **请求 URL**：`https://mail.njfu.edu.cn/`
- **关键请求头**：
  ```http
  User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/116.0.0.0 Safari/537.36
  ```
- **核心响应提取**：
  在首页 HTML 源码中，包含用于防重放攻击的动态时间戳：
  ```html
  <script nonce="...">
  var g_nTimeStamp = "1793865950";
  // 或正则匹配：nTimeStamp\s*:\s*"(\d+)"
  </script>
  ```

---

## 阶段二：RSA 加密与构造载荷

### 1. 公钥参数
系统采用固定 1024-bit RSA 公钥：
- **Modulus (N)**:
  ```
  CF87D7B4C864F4842F1D337491A48FFF54B73A17300E8E42FA365420393AC0346AE55D8AFAD975DFA175FAF0106CBA81AF1DDE4ACEC284DAC6ED9A0D8FEB1CC070733C58213EFFED46529C54CEA06D774E3CC7E073346AEBD6C66FC973F299EB74738E400B22B1E7CDC54E71AED059D228DFEB5B29C530FF341502AE56DDCFE9
  ```
- **Exponent (E)**:
  ```
  10001 (十进制: 65537)
  ```

### 2. 待加密明文格式
```python
message = f"{PASSWORD}\n{timestamp}\n"
```
> [!IMPORTANT]
> 必须在密码后跟换行符 `\n`，再跟 `nTimeStamp`，最后再以 `\n` 结尾。

### 3. 加密模式
- **填充规范**：PKCS#1 v1.5 (`PKCS1_v1_5.new(pub_key)`)
- **编码格式**：加密后进行标准 Base64 编码，生成字符串 `p_b64`。

---

## 阶段三：POST 提交登录

- **请求方式**：`POST`
- **请求 URL**：`https://mail.njfu.edu.cn/cgi-bin/login`
- **Content-Type**：`application/x-www-form-urlencoded`
- **请求 Body 参数表**：

| 参数名 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| `uin` | string | 账号/学号/工号 | `2410403132` |
| `domain` | string | 邮箱域名 | `njfu.edu.cn` |
| `pp` | string | Base64 编码的 RSA 密文 | `h8L3v...==` |
| `p` | string | 同 `pp` 字段 | `h8L3v...==` |
| `verifycode` | string | 验证码（正常情况下为空字符串） | `""` |
| `f` | string | 客户端标识 | `biz` |
| `aliastype` | string | 别名类型 | `other` |
| `ppp` | string | 备用字段（留空） | `""` |
| `fun` | string | 扩展字段（留空） | `""` |
| `errtemplate` | string | 错误模板名 | `new_index/index` |

---

## 阶段四：提取 Session ID (`sid`)

登录请求提交后，服务器返回 `302 Found` 重定向或一段含有页面跳转逻辑的 HTML 代码：

```html
targetUrl = urlHead + "frame_html?sid=Trx-hF5nyf8TnRx2,7&r=...";
```

- **提取正则**：
  ```python
  sid_match = re.search(r'targetUrl\s*=\s*urlHead\s*\+\s*"frame_html\?sid=([^"&]+)', response.text)
  sid = sid_match.group(1)
  ```
- **作用**：此 `sid` 即为全局会话令牌，后续所有接口（邮件列表、读取正文、下载附件）均需在 URL Query 参数中带上 `sid`。

---

## 登录 Python 代码参考

```python
import base64
import re
from curl_cffi import requests
from Crypto.Cipher import PKCS1_v1_5
from Crypto.PublicKey import RSA

LOGIN_URL = "https://mail.njfu.edu.cn/"
POST_LOGIN_URL = "https://mail.njfu.edu.cn/cgi-bin/login"
RSA_N_HEX = "CF87D7B4C864F4842F1D337491A48FFF54B73A17300E8E42FA365420393AC0346AE55D8AFAD975DFA175FAF0106CBA81AF1DDE4ACEC284DAC6ED9A0D8FEB1CC070733C58213EFFED46529C54CEA06D774E3CC7E073346AEBD6C66FC973F299EB74738E400B22B1E7CDC54E71AED059D228DFEB5B29C530FF341502AE56DDCFE9"
RSA_E_HEX = "10001"

def login(username, password, domain="njfu.edu.cn"):
    # 模拟 Chrome TLS 指纹，并显式绕过本地代理
    session = requests.Session(impersonate="chrome116", proxies={"http": None, "https": None})
    
    # 1. 获取时间戳
    resp = session.get(LOGIN_URL)
    resp.raise_for_status()
    timestamp = re.search(r'nTimeStamp\s*:\s*"(\d+)"', resp.text).group(1)
    
    # 2. RSA 加密
    message = f"{password}\n{timestamp}\n".encode("utf-8")
    pub_key = RSA.construct((int(RSA_N_HEX, 16), int(RSA_E_HEX, 16)))
    cipher = PKCS1_v1_5.new(pub_key)
    p_b64 = base64.b64encode(cipher.encrypt(message)).decode("utf-8")
    
    # 3. 提交登录
    payload = {
        "uin": username,
        "domain": domain,
        "pp": p_b64,
        "verifycode": "",
        "f": "biz",
        "aliastype": "other",
        "p": p_b64,
        "ppp": "",
        "fun": "",
        "errtemplate": "new_index/index",
    }
    login_resp = session.post(POST_LOGIN_URL, data=payload, allow_redirects=False)
    
    # 4. 解析 sid
    sid = re.search(r'targetUrl\s*=\s*urlHead\s*\+\s*"frame_html\?sid=([^"&]+)', login_resp.text).group(1)
    return session, sid
```
